NVIDIA API Anahtar Testi

build.nvidia.com anahtarının (nvapi-…) çalışıp çalışmadığını dene. Anahtar hiçbir yere kaydedilmez; sayfayı kapatınca silinir.

Yalnızca doğrudan NVIDIA'ya (integrate.api.nvidia.com) gönderilir.

Sayfa bağlanamazsa: GitHub Actions ile test

NVIDIA, API'sine tarayıcıdan yalnızca kendi sitelerinden izin veriyor (CORS). O yüzden yukarıdaki test "bağlantı engellendi" hatası verebilir. Bu durumda aynı testi GitHub'ın sunucusunda çalıştır. Telefondan da olur:

  1. Bir kerelik: anahtarı repo'ya gizli olarak ekle. Ad: NVIDIA_API_KEY, değer: anahtarın. 1) Secret ekle
  2. Run workflow'a bas, model ve mesajı yaz, yeşil butona bas. 2) Testi çalıştır
  3. Yaklaşık 20 saniye sonra çalışmaya dokun. Cevap Summary bölümünde görünür. Anahtar loglarda gizlenir.
